Privacy Policy

Last updated: October 18, 2026

This Privacy Policy explains how CalCatch (“the add-on”), a Gmail add-on developed by wisteria3221 (“the developer”), accesses, uses, stores and shares data. CalCatch runs on Google Apps Script within your Google account. The developer does not operate any server for CalCatch and does not receive your data.

1. Data the add-on accesses

DataWhen and whyGoogle permission (scope)
The email you have open in Gmail (body text, subject, sender, received date) Only for the email you open while CalCatch is shown, to find the events written in it. gmail.addons.current.message.readonly, gmail.addons.execute
Events on calendars you own, around the dates found in the email (title, time, description) To warn you when the same or a similar event is already in your calendar. calendar.events.owned
Events you choose to add Created on your primary calendar only when you press “Add to Calendar”. calendar.events.owned
Your calendar list and calendar time zone To know which calendars you own and to interpret dates in your time zone. calendar.calendarlist.readonly
Your Gmail display language To show the add-on in Japanese or English. script.locale

The add-on also uses script.external_request to call the Gemini API.

2. How the data is used

The data above is used only to provide CalCatch’s features: extracting events from the open email, checking for duplicates, and adding the events you select to your calendar. It is not used for advertising, profiling, or any other purpose.

3. Sharing with the Google Gemini API

To extract events, the body text, subject, sender and received date of the open email are sent to the Google Gemini API (generativelanguage.googleapis.com) using the Gemini API key that you provide. This transfer is governed by the Gemini API terms that apply to your API key. On the Gemini API free tier, Google may use the content you send to improve its products; with a paid-tier key it does not. Choose the type of key that fits your needs.

No data is shared with the developer or with any other third party.

4. Storage and retention

  • Your Gemini API key and model choice are stored in Apps Script User Properties, which belong to your Google account and are not accessible to other users. The full key is never displayed after it is saved.
  • Extracted event candidates are kept in the Apps Script user cache for up to 6 hours so that reopening the same email is fast and does not call the Gemini API again. They are then deleted automatically.
  • Email content is not stored by the add-on.
  • Events you add stay in your Google Calendar until you delete them.

5. Deleting your data

  • Remove your API key at any time from Settings → Remove API key.
  • Uninstall the add-on and revoke its access from your Google Account at myaccount.google.com/permissions.
  • Cached event candidates expire within 6 hours.

6. Limited Use disclosure

CalCatch’s use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google Workspace user data obtained through Google Workspace APIs is not used to develop, improve, or train generalized AI or machine learning models.

7. Security

All communication with Google services, including the Gemini API, uses HTTPS. The add-on’s source code is public at github.com/wisteria3221/calcatch.

8. Children

CalCatch is not directed to children under 13 and does not knowingly collect data from them.

9. Changes to this policy

If this policy changes, the updated version will be posted on this page with a new “Last updated” date.

10. Contact

For questions about this policy, please contact us via GitHub Issues.
