プライバシーポリシー

最終更新日：2026年10月18日

このプライバシーポリシーは、wisteria3221（以下「開発者」）が開発する Gmail アドオン CalCatch（以下「本アドオン」）が、どのようなデータにアクセスし、どのように利用・保存・共有するかを説明するものです。本アドオンは、あなたの Google アカウント内の Google Apps Script 上で動作します。開発者は本アドオンのためのサーバーを運用しておらず、あなたのデータを受け取ることはありません。

本ページは英語版（Privacy Policy）の日本語訳です。内容に相違がある場合は英語版が優先されます。

1. 本アドオンがアクセスするデータ

データアクセスする場面と目的Google の権限（スコープ）
Gmail で開いているメール（本文、件名、差出人、受信日時） 本アドオンを表示した状態で開いたメールに限り、本文に書かれた予定を見つけるために読み取ります。 gmail.addons.current.message.readonly、gmail.addons.execute
メールで見つかった日付の前後にある、あなたが所有するカレンダーの予定（タイトル、日時、説明） 同じ予定や似た予定がすでに登録されている場合に知らせるために読み取ります。 calendar.events.owned
あなたが登録を選んだ予定 「カレンダーに登録」を押したときだけ、メインのカレンダーに作成します。 calendar.events.owned
カレンダーの一覧とタイムゾーン 所有しているカレンダーを把握し、日時をあなたのタイムゾーンで扱うために読み取ります。 calendar.calendarlist.readonly
Gmail の表示言語 本アドオンを日本語または英語で表示するために読み取ります。 script.locale

また、Gemini API を呼び出すために script.external_request を使用します。

2. データの利用目的

上記のデータは、本アドオンの機能（開いているメールからの予定の抽出、重複の確認、選んだ予定のカレンダーへの登録）を提供するためだけに利用します。広告、プロファイリング、その他の目的には利用しません。

3. Google Gemini API への送信

予定を抽出するため、開いているメールの本文・件名・差出人・受信日時を、あなたが設定した Gemini API キーを使って Google の Gemini API（generativelanguage.googleapis.com）に送信します。この送信には、あなたの API キーに適用される Gemini API の利用規約が適用されます。Gemini API の無料枠では、送信した内容が Google のサービス改善に使われる場合があります。有料枠のキーでは使われません。用途に合ったキーをお選びください。

開発者やその他の第三者とデータを共有することはありません。

4. データの保存と保存期間

  • Gemini API キーとモデルの設定は、あなたの Google アカウントに属する Apps Script のユーザープロパティに保存され、他の利用者からはアクセスできません。保存後にキー全体が表示されることはありません。
  • 抽出した予定の候補は、同じメールを開き直したときにすばやく表示し、Gemini API を再度呼び出さずに済むよう、Apps Script のユーザーキャッシュに最大6時間保持し、その後自動的に削除されます。
  • メールの内容を本アドオンが保存することはありません。
  • 登録した予定は、あなたが削除するまで Google カレンダーに残ります。

5. データの削除

  • API キーは「設定」→「API キーを削除」からいつでも削除できます。
  • 本アドオンをアンインストールし、myaccount.google.com/permissions からアクセス権を取り消すことができます。
  • キャッシュされた予定の候補は、6時間以内に自動的に削除されます。

6. 限定的使用（Limited Use）に関する開示

本アドオンによる Google API から受け取った情報の利用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。Google Workspace API を通じて取得した Google Workspace のユーザーデータを、汎用的な AI や機械学習モデルの開発・改善・学習に使用することはありません。

7. セキュリティ

Gemini API を含む Google のサービスとの通信は、すべて HTTPS で行われます。本アドオンのソースコードは github.com/wisteria3221/calcatch で公開しています。

8. 子どもの利用

本アドオンは13歳未満の子どもを対象としておらず、子どもからデータを意図的に収集することはありません。

9. 本ポリシーの変更

本ポリシーを変更する場合は、最終更新日を改めたうえで、このページに掲載します。

10. お問い合わせ
