最終更新日：2026年10月18日

1. サービスの内容

本アドオンは、開いているメールに書かれた予定を Google Gemini API で抽出し、カレンダーとの重複を確認したうえで、あなたが選んだ予定を Google カレンダーに登録します。本アドオンは無料で提供されます。

2. Gemini API キーと費用

本アドオンの利用には、あなた自身の Gemini API キーが必要です。Gemini API の利用には、あなたのキーに適用される利用規約が適用され、利用料金はキーを発行した Google Cloud プロジェクトに請求されます。キーの管理、利用上限、費用はあなたの責任で管理してください。

予定の抽出は AI モデルによって行われるため、不完全または誤っている場合があります（日付・時刻・場所の誤りなど）。重複の判定も目安です。登録する前に、必ず内容を確認してください。予定の見落とし・誤り・重複について、開発者は責任を負いません。
