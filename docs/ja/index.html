CalCatch
プライバシーポリシー 利用規約 English

メールの予定を見つけて、Google カレンダーへ。

CalCatch は Gmail アドオンです。メールを開くと、本文に書かれた日時や場所を Gemini で読み取り、そのまま Google カレンダーに登録できます。

  • 本文から自動で読み取りメールを開くと、予定名・日時・場所・メモを抽出します。
  • 二重登録を防止カレンダーに登録済みと思われる予定には警告を表示し、チェックを外しておきます。
  • 登録は自分で決める登録したい予定にチェックを入れて「カレンダーに登録」を押すまで、何も登録されません。
  • 自分の API キーで動作Gemini API はあなた自身のキーで呼び出します。CalCatch 独自のサーバーはありません。

しくみ

  1. CalCatch をインストールし、Gmail でメールを開きます。
  2. CalCatch があなたの API キーでメールを Gemini API に送り、見つかった予定を一覧表示します。
  3. カレンダーに同じ予定や似た予定がないかを確認し、重複の可能性があれば知らせます。
  4. 登録したい予定にチェックを入れて「カレンダーに登録」を押します。予定の説明欄には元のメールへのリンクが入ります。

はじめかた

  1. Google AI Studio で Gemini API キーを発行します。
  2. Gmail のサイドパネルで CalCatch を開き、アドオンのメニューから「設定」を選びます。
  3. API キーを貼り付けて保存します。Gemini のモデル（標準・軽量・高精度・任意のモデル名）も選べます。

Gemini API の料金は、API キーを発行した Google Cloud プロジェクトに請求されます。Gemini API の無料枠では、送信した内容が Google のサービス改善に使われる場合があります。気になる場合は、課金を有効にしたキーを使ってください。

プライバシー

CalCatch が読み取るのは、開いているメールと、見つかった日付の前後にあるあなた自身のカレンダーの予定だけです。独自のサーバーは持たず、データを収集・販売したり、開発者を含む第三者と共有したりしません。メールの内容は、あなた自身の API キーで Google の Gemini API にのみ送信されます。詳しくはプライバシーポリシーをご覧ください。
