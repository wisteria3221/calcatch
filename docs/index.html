Catch the events in your email, add them to Google Calendar.

CalCatch is a Gmail add-on. Open an email and it reads the dates, times and places written in it with Gemini, so you can add them to Google Calendar in one step.

  • Reads the email for youEvent title, date, time, place and notes are extracted when you open an email.
  • Avoids duplicatesEvents that look already registered in your calendar are flagged and left unchecked.
  • You stay in controlNothing is added until you check the events you want and press “Add to Calendar”.
  • Your own API keyCalCatch calls the Gemini API with your own key. There is no CalCatch server.

How it works

  1. Install CalCatch and open an email in Gmail.
  2. CalCatch sends the email to the Gemini API with your API key and lists the events it found.
  3. It checks your calendars for the same or similar events and warns you about possible duplicates.
  4. Check the events you want and press Add to Calendar. Each event includes a link back to the original email.

Getting started

  1. Create a Gemini API key in Google AI Studio.
  2. In Gmail, open CalCatch from the side panel and choose Settings from the add-on menu.
  3. Paste your API key and save. You can also choose the Gemini model (Standard, Lite, Pro, or a model name of your choice).

Gemini API usage is billed to the Google Cloud project that owns your API key. On the Gemini API free tier, content you send may be used to improve Google products. If that concerns you, use a key with billing enabled.

Privacy

CalCatch reads only the email you open and the events on your own calendars around the dates it finds. It does not run its own server and does not collect, sell, or share your data with the developer or anyone else. Email content is sent only to the Google Gemini API, using your own API key. See the Privacy Policy for details.
